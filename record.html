GitHub: not set up

Recordings are saved on this device until you send them. Sending commits them to the repo in one go, and GitHub Pages republishes the game a minute or two later.

To send, this page needs a fine-grained personal access token: in GitHub, go to Settings → Developer settings → Fine-grained tokens → Generate new token, choose Only select repositories and pick this game's repo, then under Repository permissions set Contents to Read and write. Give it an expiry date. The token stays in this browser only.
